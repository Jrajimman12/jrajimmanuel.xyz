Current Development
Dynamic Forecast of Expected Time of Arrival (ETA) for Coaching Trains
Probabilistic ForecastingReal-Time APIPredictive Modelling

An ETA service that ingests live train position and current delay, and for each remaining station on the run predicts arrival as a distribution rather than a point, using features grounded in real running behaviour — sectional running time history for that route, delay of the preceding train on the same section, downstream congestion, station-specific dwell behaviour, day of week and seasonal effects, and the recovery time actually built into the schedule — refreshing predictions on each new position update, degrading gracefully when position data is stale, and exposed through an API sized for network-wide operation with an accompanying view for passengers and control room staff showing predicted arrival with an uncertainty band.

ChurchOne - A Management SW
Visual BasicDesktop App (.exe)Data Management

Developed a comprehensive church management application to manage member records, family trees, offerings, announcements, and daily Bible verses. Authorized management personnel can securely log in using their ID and password to add, delete, and modify member details, update funds and announcements, manage daily verses, and control user access permissions. Integrated a custom-built WhatsApp API that allows members to access services by sending “Hi” to the church’s WhatsApp number, receiving a numbered menu with options for announcements, daily word registration/unregistration, offerings, addresses, family details, and church bank details. Members can view their birthdays, family information, and offerings, with an option to mask offering amounts for privacy. The system automatically sends daily verses and announcements to registered members, birthday wishes to members, and birthday reminders to their families. It also maintains validated family addresses and phone numbers for generating invitation lists without repeatedly collecting information. Authorized personnel can retrieve weekly birthday reports directly through WhatsApp, while designated editors can correct daily verses by sending an updated version beginning with “EDIT”, which the system verifies and updates within approximately one minute. Overall, the application streamlines church administration, automates communication, protects member privacy, and simplifies record management through an integrated web and WhatsApp-based system.
